# Superstore Sales Analysis Dashboard

This project presents a business intelligence dashboard built using **Microsoft Excel** to analyze Superstore sales performance.

---

## 📌 Key Insights & KPIs
- **Total Sales:** ₹147266.4
- **Best Performing Category:** Electronics
- **Highest Revenue Region:** West

---

## 📊 Dashboard Visuals
The dashboard includes four professional performance charts:
| Visual | Purpose |
|--------|----------|
| Sales by Region | Identifies geographical contribution to total sales |
| Sales by Category | Compares revenue across product categories |
| Monthly Sales Trend | Shows seasonality and sales fluctuation over time |
| Profit Margin by Category | Measures category profitability |
